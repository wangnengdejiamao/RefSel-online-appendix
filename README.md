# RefSel: Online Appendix

Online appendix for the paper **"RefSel: Risk-Controlled Foreign-Key Discovery with Bounded Language-Model Evidence"** by Jiamao Lin and Weisong Sun (manuscript in preparation for IEEE Transactions on Knowledge and Data Engineering).

- [RefSel_online_appendix.pdf](RefSel_online_appendix.pdf) contains the proofs, implementation details, risk-calibration formulas, the audit of calibration errors, use cases and pseudocode, supplementary tables, extended method details, and the full-length experimental report.

Section, table, figure, equation, and algorithm numbers with the prefix A refer to the appendix; all other numbers refer to the main paper.
